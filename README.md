# FPP Jukebox

FPP plugin providing a touchscreen jukebox allowing guests to select
individual FPP sequences.

## Features

- Touchscreen guest interface
- Individual FPP sequence selection
- Enable/disable sequences
- Custom sequence ordering
- Artwork support
- Configurable lockout
- FPP sequence playback
- FPP playback status monitoring

## Requirements

- FPP 8 or later
- FPP sequences
- Touchscreen/browser device

## Installation

Clone the repository into the FPP plugin manager or install through
FPP Plugin Manager.

The plugin installation script creates the required plugin data
directories and default configuration.

## Guest Interface

The guest interface is provided by the plugin and communicates with
the plugin API.

## Configuration

Configuration is available from the FPP Plugin Manager plugin page.
